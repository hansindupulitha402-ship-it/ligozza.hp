LIGOZZA MODERN CLOTHING WEBSITE

UPDATED FEATURES
- Multi-page Home / Shop / Product / Cart / Category navigation
- Separate Men / Women / Accessories / New Arrivals pages
- Product detail pages with selectable sizes
- Clothing sizes: S, M, L, XL, XXL
- Accessories can use One Size
- Product gallery supports multiple images (add 2, 3, or more)
- Product page shows image thumbnails and lets customers switch images
- Admin page lets you edit product name, price, category, description, sizes and images
- Multiple images can be uploaded together from phone/computer
- Cart remembers selected size and quantity
- Data is stored in browser localStorage

HOW TO USE
1. Open index.html.
2. Open admin.html to edit products.
3. Select a product.
4. Tick the sizes you want customers to see.
5. Click “Add 2–3 or more images” and select multiple photos.
6. Save Changes.
7. Open the product page to see the gallery and size selector.

NOTE
This is a front-end demo/store template. Payment gateway, real database, customer accounts and live order processing need a backend/service connection.
